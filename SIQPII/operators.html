1.2. Operators and states

So far, we've just done math. The time has come to interpret things physically. Each operator \(A \in \mathcal{A}\) has a set of eigenvalues, scalars \(\lambda \in \mathbb{C}\) such that \(A - \lambda I\) has no multiplicative inverse. We call this set the spectrum of \(A\), labelled \(\text{spec}(A)\). If an operator satisfies a minimalIn other words, no polynomial \(p'\) of lower degree satisfies \(p'(A, A^*) = 0\). polynomial identity \(p(A, A^*) = 0\), then the complex solutions \(p(\lambda, \overline{\lambda})\) constitute the spectrum. For instance, in the Pauli algebra (\(d = 2\)), the Pauli \(X\) operator satisfies \[ X^2 - I = 0 \quad \Longrightarrow \quad \lambda^2 - 1 = 0 \quad \Longrightarrow \quad \text{spec}(X) = \{1, -1\}. \] We can reproduce this calculation using the spec() function in yaw: 

*> $alg = qubit()
*> spec(X)
[1, -1]

You can compute the spectrum for qudit operators similarly: 

*> $alg = qudit(3)
*> spec(X)
[1, (-0.5+0.866j), (-0.5-0.866j)]

This even works in infinite dimensions. The spectrum of the unitary generator \(U\) (with no other constraints) is the unit circle: \[ |U|^2 - I = 0 \quad \Longrightarrow \quad |\lambda|^2 - 1 = 0 \quad \Longrightarrow \quad \text{spec}(U) = \mathbb{S}^1. \] You can view this result a few different ways in Exercise 1.3.

The deep physical insight of quantum mechanics is as follows: measuring an operator means observing its eigenvalues at random. Put more carefully, measurement turns each \(A\in\mathcal{A}\) into a random variable with values \(\lambda \in \text{spec}(A)\). We write \(A \leftarrow \lambda\) for this observation, or \(A \overset{\pi}{\leftarrow} \lambda\) if we want to make the state explicit. We can decompose a diagonalizableReally, we mean an operator obeying the spectral theorem. operator \(A\) into a sum of orthogonal projectors, \[ A = \sum_{\lambda \in \text{spec}(A)} \lambda \Pi^{(A)}_\lambda, \quad \Pi^{(A)}_\lambda \Pi^{(A)}_\mu = \delta_{\mu\lambda}\Pi^{(A)}_\lambda. \] These projectors can often be written entirely in terms of \(A\). For instance, the Pauli \(Z\) operator can be written \[ Z = \Pi^{(Z)}_{+1} - \Pi^{(Z)}_{-1}, \quad \Pi^{(Z)}_{\pm 1} = \frac{1}{2}(I \pm Z). \] In yaw, projectors are accessed using proj(A, k), where \(k\) enumerates eigenvalues in the same order they appear in spec(A): 

*> $alg = qudit(2)
*> proj(Z, 0)
proj(Z, 0)
*> proj(Z, 0).expand()
1/2 + Z/2
*> proj(Z, 1).expand()
1/2 - Z/2

We force yaw to display the functional form of the projector with .expand(), which otherwise remains proj(A, k).

The projector \(\Pi^{(A)}_\lambda\) has a binary spectrum,Since \(\Pi^2 - \Pi = \Pi(\Pi - I) = 0\), with eigenvalues \(\lambda = 0, 1\). with \(\Pi^{(A)}_\lambda \leftarrow 1\) just in case \(A \leftarrow \lambda\) and otherwise \(\Pi^{(A)}_\lambda \leftarrow 0\). Thus, the expectation of \(\Pi^{(A)}_\lambda\) is precisely the probability that \(A \leftarrow \lambda\): \[ \label{eq:6} \mathbb{E}[\Pi^{(A)}_\lambda] = 1\cdot\mathbb{P}[\Pi^{(A)}_\lambda \leftarrow 1] + 0 \cdot\mathbb{P}[\Pi^{(A)}_\lambda \leftarrow 0] = \mathbb{P}[A \leftarrow \lambda]. \] Thus, from projectors and expectations we recover all the measurement probabilities! The first part of this equation—the projectors—are recoverable from the relevant operators \(A\). The expectation function \(\mathbb{E}\) is more mysterious.
A journey full of expectation. It turns out that, in the algebraic framework, expectations are states. There is no Hilbert space of vectors (for now), just a set \(S(\mathcal{A})\) of consistent expectation functions. Expectation functions are linear, normalized, and positive, in the sense that \[ \label{eq:3} \mathbb{E}_\pi\left[\sum_i \alpha_i A_i\right] = \sum_i \alpha_i \mathbb{E}_\pi[A_i], \quad \mathbb{E}_\pi[I] = 1, \quad \mathbb{E}_\pi[|A|^2] \geq 0, \] where \(|A|^2\) automatically has positive eigenvalues \(|\lambda|^2\). We turn this round and define a state as a positive, normalized functional.The term “functional” implies linearity. The two definitions are equivalent, as you'll show in Exercise 2.1.

The simplest way to prepare states is to make measurements. If you measure \(A\) and observe \(\lambda\), you'll now be in a state where \(A \leftarrow \lambda\) with probability \(1\). We write the state as \(\pi^{(A)}_\lambda\), and by definition, \[ \label{eq:7} \pi^{(A)}_\lambda[\Pi^{(A)}_\mu] = \delta_{\mu\lambda}. \] In yaw, you can invoke the state using char(A, k), which uses the same indexing as proj(A, k). We apply a state-as-expectation-functional using the pipe notationThe reason for this choice will become clear in the next section. A|state:Note that using pi as a variable clashes with the existing numerical meaning, so we use psi instead. 

*> psi0 = char(Z, 0)
*> proj(Z, 0) | psi0
1
*> proj(Z, 1) | psi0
0.0

We can always take a convex combination of expectation functions, \[ \mathbb{E} = p_1 \mathbb{E}_1 + (1-p_1)\mathbb{E}_2, \] for \(p_1 \in [0, 1]\). You can check this remains linear, positive and normalized, and hence a valid expectation. This just probabilistically reframes the old idea of mixing states. In yaw, this is straightforward: 

*> psi1 = char(Z, 1)
*> proj(Z, 0) | 0.2*psi0 + 0.8*psi1
0.2

This is not the same as adding vectors in Hilbert space; a feature and a bug of the algebraic approach is that this sort of &ldquo;coherent&rdquo; addition is difficult.It's a bug because we're used to thinking this way. It's a feature because we shouldn't be thinking this way!

Although difficult, it is not impossible. We can recover the usual Hilbert space using a technique called the Gelfand-Naimark-Segal (GNS) construction. We won't belabour the details, but the basic point is that, given a state \(\pi \in S(\mathcal{A})\), we can build a Hilbert space \(\mathcal{H}_\pi\) from \(\mathcal{A}\) itself, with inner productThe catch is that we have to identify \(A\) and \(B\) with an entire class of operators. See Exercise 2.2 for more. \[ \langle A, B \rangle_\pi = \pi (A^*B). \] An operator then corresponds to a vector \(|B\rangle_\pi\), and operators in \(\mathcal{A}\) act via \(A|B\rangle_\pi =|AB\rangle_\pi\). Thus, operators have two roles: vectors and matrices. With yaw, you can access the former using gnsVec(state, operator) and the latter with gnsMat(state, operator): 

*> $alg = qudit(2)
*> gnsVec(char(Z, 0), X)
[0.+0.j 1.+0.j]
*> Y = 1.j*X*Z
*> gnsMat(char(Z, 0), Y)
[[0.+0.j 0.-1.j]
 [0.+1.j 0.+0.j]]

The advantage of Hilbert space is that (in the finite-dimensional case) it explicitly lists all the pure states, that is, states that cannot be obtained by mixing. By mixing them, we get all possible states, so the density matrices \(\mathcal{M}(\mathcal{H}_\pi) = S(\mathcal{A})\). This is a beautiful result!Why? Because it's not obvious that we had to get all the pure states via GNS, or that mixing should be the only operation needed to obtain the rest.

Let's summarize. Measurement turns operators into a random distribution over eigenvalues; states are consistent expectation functionals for this distribution across the whole algebra; we can recover probabilities by taking the expectation of projectors; and finally, we can describe the full set of pure states using the GNS construction, and by mixing, get \(S(\mathcal{A})\). It's an elegant state of affairs.
